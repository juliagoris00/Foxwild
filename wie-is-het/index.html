Wie is het?

Een competitief “wie van ons?”-spel. Raad niet alleen wie jij vindt, maar vooral wie de meeste auto’s gaan kiezen.

1. Vraag
De host start een ronde met timer.
2. Overleg
Elke auto kiest één naam + motivatie.
3. Inzet
Kies 1, 3 of 5 punten.
4. Onthullen
Meerderheid goed? Inzet erbij. Fout? Inzet eraf.
